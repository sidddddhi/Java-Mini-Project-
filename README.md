# Java-Mini-Project-
Smart Vehicle Parking System
A Java-based OOP mini project designed to manage parking administration and vehicles.

Current Modules

Module 1 – Admin Management
*Create admin account
*Login
*Change password
*Logout

Module 2 – Vehicle Management
*Register vehicle
*Search vehicle
*Update vehicle
*Remove vehicle
*View all vehicles

VS Code
*OOP Concepts
*Encapsulation
*Inheritance
*Abstraction
*Polymorphism
